Description

Cette unité stoke les informations d'une espèce d'arbre ainsi que ses différentes phases de croissance (de la graine à la maturité)

Overview

Classes, Interfaces, Objects and Records

Name Description
Record TPhase Une "image" de l'arbre à un instant donné de sa croissance.
Record TTree Une espèce d'arbre complète, avec son nom, sa description, et l'ensemble de ses phases de croissance.

function initialiseTree(): TTree;

Construit un arbre vide.

Le nom et la description sont vides, et aucune phase n'est encore définie (nbPhase = 0). Chaque case du tableau phase est pré-initialisée (phase vide).

Returns

Un nouvel arbre vierge.

procedure setPhase(var tree: TTree; phaseNb: LongInt; phase: TPhase);

Définit une phase de croissance de l'arbre.

Si phaseNb dépasse nbPhase, celui-ci est automatiquememt étendu jusqu'à phaseNb. Ne fait rien si phaseNb dépasse MAX_PHASE.

Parameters
tree
L'arbre modifié (passé par référence).
phaseNb
Numéro de la phase définie.
phase
Contenu de la phase à enregistrer.
